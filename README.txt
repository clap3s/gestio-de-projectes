PRACTICA — DASHBOARDING CON DATOS ABIERTOS E IA

Tema: Población de Barcelona por distrito, 2019–2024

IMPORTANTE — CÓMO ABRIR:
1. Abre index.html con doble clic.
2. Pulsa "Seleccionar archivo".
3. Dentro de la carpeta data, selecciona:
   poblacion_distritos_bcn_2019_2024.csv
4. El dashboard cargará los datos y habilitará el filtro.

No es necesario usar un servidor local para cargar el CSV: el dashboard utiliza FileReader,
por lo que funciona al abrir index.html directamente.

Contenido:
- index.html: dashboard interactivo.
- sobre.html: fuente, método, limitaciones y declaración de uso de IA.
- data/poblacion_distritos_bcn_2019_2024.csv: datos.
- PROMPTS_usados.txt: prompts utilizados.
- README.txt: instrucciones.

Fuente:
Ajuntament de Barcelona — Open Data BCN — Padró municipal d'habitants (pad_mdbas).
